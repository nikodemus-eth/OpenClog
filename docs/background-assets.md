# OpenClog Background Assets

## 2026-05-02 Theme Background Notes
- `journal-paper.svg` is a copyright-safe paper grain made from ruled lines and neutral speckles.
- `command-console.svg` is an abstract starfield and console silhouette; it avoids franchise logos, proprietary shapes, and exact branded interface geometry.
- `manuscript-surface.svg` uses generic manuscript flourishes, ruled lines, and warm surface texture without copying game art.
- `map-table.svg` uses generic chart lines, compass geometry, and map paths without copying film, game, or franchise assets.
- `news-media.svg` uses generic broadcast-control blocks and ticker bands without external logos or exact media trade dress.
- `publication-sheet.svg` uses generic publication columns and market-ledger lines without newspaper logos or masthead copies.
- `social-feed.svg` uses generic feed cards, circular profile motifs, and connector lines without external social-platform assets.
- `desktop-shell.svg` uses generic window chrome and desktop panels without proprietary OS logos or glyphs.
- `terminal-grid.svg` uses generic terminal grid lines and prompt-like strokes without branded terminal artwork.
- `accessibility-calm.svg` uses low-noise color fields for calm accessibility surfaces.
- All backgrounds are local, static, decorative, non-interactive, and removable without changing OpenClog information architecture.
